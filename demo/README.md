# Демонстрационная информационная база

`pyaterochka-demo.dt` — выгрузка изолированной файловой базы 1С:Предприятия 8.3.27.1936. В ней заранее доступны демонстрационные записи каталогов:

- 1 магазин, 1 склад, 1 поставщик и 1 касса ККМ;
- 10 товаров повседневного спроса.

Все значения вымышлены. Адрес и контакты являются заглушками; штрихкоды используют синтетическую последовательность. В базе пока нет документов, записей цен и движений по регистрам: их можно создать вручную на основе загруженных справочников.

## Восстановление через Конфигуратор

Создайте пустую файловую базу, откройте её в Конфигураторе и выберите **Администрирование → Загрузить информационную базу…**, затем укажите этот `.dt`-файл. Загрузка заменит содержимое целевой базы.

## Восстановление через ibcmd

```sh
ibcmd infobase create \
  --database-path="/путь/к/новой-базе" \
  --data="/путь/к/каталогу-данных-ibcmd" \
  --restore="pyaterochka-demo.dt" \
  --force
```

Файл выгружен и проверен восстановлением в отдельную временную базу. Это проверяет целостность `.dt`, но не заменяет функциональную проверку документов в интерактивном режиме 1С.
