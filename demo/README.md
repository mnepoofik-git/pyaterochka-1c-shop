# Демонстрационная информационная база

Версия конфигурации: **0.1.1**.

`pyaterochka-demo.dt` — выгрузка изолированной файловой базы 1С:Предприятия 8.3.27.1936. При первом запуске восстановленной базы в режиме «1С:Предприятие» конфигурация добавляет демонстрационные записи:

- 1 магазин, 1 склад, 1 поставщик и 1 касса ККМ;
- 10 товаров повседневного спроса.

Все значения вымышлены. Адрес и контакты являются заглушками; штрихкоды используют синтетическую последовательность. Сама выгрузка `.dt` сделана до первого запуска, поэтому записи создаются при первом открытии «1С:Предприятие», а не при восстановлении файла. Документы, цены и движения по регистрам не создаются.

## Восстановление через Конфигуратор

Создайте пустую файловую базу, откройте её в Конфигураторе и выберите **Администрирование → Загрузить информационную базу…**, затем укажите этот `.dt`-файл. Загрузка заменит содержимое целевой базы.

## Восстановление через ibcmd

```sh
ibcmd infobase create \
  --database-path="/путь/к/новой-базе" \
  --data="/путь/к/каталогу-данных-ibcmd" \
  --restore="pyaterochka-demo.dt" \
  --force
```

После восстановления запустите базу в режиме «1С:Предприятие»: процедура заполнения создаст записи при первом старте и пропустит уже существующие коды. Файл проверен восстановлением и проверкой метаданных на платформе 8.3.27.1936. В исправленной версии для всех справочников задана длина наименования; успешное отображение записей после старта ещё требует проверки в интерфейсе.

## Обновление базы, которую уже создали

Если у вас открыта прежняя пустая база, закройте «1С:Предприятие», затем откройте эту же базу в Конфигураторе. Выберите **Конфигурация → Загрузить конфигурацию из файла…**, укажите `build/МагазинПятерочка.cf`, нажмите **F7** для обновления конфигурации базы и снова запустите «1С:Предприятие». При запуске появятся записи. Если в базе есть собственные данные, сначала сделайте резервную копию.
