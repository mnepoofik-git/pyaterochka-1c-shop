# Выполненный вариант 2 для УНФ

Решение рассчитано на исходный Данные.xlsx практикума, 38 товаров, две отдельные базы УНФ 3.0.9.150 и платформу 8.5.1.1522. Расширение «ОфисПро 2.0.cfe» ставится в обе базы. Архив исходников содержит конфигурацию расширения в XML и модули BSL. Методичка 2.docx, задание и учебный сервис лежат в корне варианта. Исходные CFE практикума остаются материалами для сравнения.

## Как повторить на своём компьютере

1. Восстанови общий стартовый DT в отдельные базы Производство и Трейд. В каждой добавь CFE через «Расширения конфигурации» и перезапусти сеанс. В этих учебных базах выдай этому расширению доступ к файлу Excel, каталогу картинок и локальному HTTP. В тесте у установленного расширения был снят флаг «Безопасный режим», флаг защиты от опасных действий был включён.
2. В Производстве распакуй Картинки.zip. В форме «Импорт» укажи полный путь к оригинальному XLSX и каталог JPG на компьютере, где работает сервер 1С. Нажми «Загрузить каталог» дважды. Убедись, что артикул 1002 находится в разделе «Бумажная продукция → Блокноты». У стартовой демобазы встречаются совпадающие артикулы за пределами трёх учебных разделов.
3. В той же форме задай пароль из задания и нажми «Подготовить доступ OData». В терминале запусти публикацию командой ниже, подставив путь к своей файловой базе производителя. Терминал оставь открытым на время работы.
4. В Трейде в форме «Пополнение» подготовь контрольные остатки. В форме проверки OData укажи URL, пользователь обмена и выбранный при подготовке пароль, сохрани настройки и проверь доступ. Затем синхронизируй каталог производителя дважды и обнови цены и остатки. Открой закупку в форме пополнения до оформления новых проведённых приходов.
5. Для Б введи в клиентскую форму дату 01.12.2026, UID контрагента «ОфисПро Трейд» из Производства, внешние UID товаров, количество и цену. Для Г отметь два товара в торговом каталоге, задай количества и открой заказ. Установи дату 02.12.2026. Запиши, подтверди отправку и запомни отдельный UID.
6. В Производстве найди торговый заказ по UID, выставь «В работе» и запиши. В Трейде проверь статус дважды. Для отдельной проверки фонового задания измени состояние на «Выполнен» в рабочий интервал и проверь историю запуска и оповещения автора. Для этого должны быть разрешены фоновые задания в БД Трейда и открыт сеанс при файловой работе.
7. Запусти независимую проверку с полученными UID и введи пароль обмена по приглашению терминала. Скрипт проверит остатки, цены, фильтр группы, сортировку, выбор полей, переход к контрагенту и обе даты и суммы заказов.

Из этой папки на macOS:

```sh
python3 Публикация.py /opt/1cv8/8.5.1.1522 "/путь/к/базе Производство"
python3 "Проверить публикацию.py" --order-b "UID-из-вкладки-POST" --order-g "UID-из-заказа-Трейда"
```

На Windows первым параметром публикации передай папку bin установленной платформы. Адрес для обеих систем — `http://localhost:8080/unf_production/odata/standard.odata/`. Для сверки каталога до создания заказов запускай проверку без параметров.
