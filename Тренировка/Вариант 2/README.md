# ОфисПро. Пробный чемпионат № 2

После самостоятельной попытки открой [выполненное решение 2.0](Разбор%20после%20попытки/Решение/README.md). В комплекте расширение для двух баз, исходники, проверка реальной публикации и протокол результатов. Методичка для этого варианта — **Методичка 2.docx**.

Самооценка решения 2.0 по 68 критериям — **88,5/100**. В локальном комплекте есть исходный Excel. Для копии с GitHub помести свой файл практикума «Данные.xlsx» в папку «Исходники».

Для самостоятельного прохода открой [задание 2](Задание.md). Для разбора используй [методичку 2 в Word](Методичка%202.docx) или [версию для браузера](Методика.md).

За 15 часов подготовь две учебные базы УНФ и защити обмен между производителем и торговой компанией. В основе тура реальные 38 артикулов из «Данные.xlsx» практикума. У этого варианта свои заказы, стартовые остатки Трейда и условия закупки. Уровень и веса взяты из тренировочной ведомости на 68 строк. Итог в тренажёре — твоя самооценка.

1. Распакуй комплект целиком в обычную папку. Открой **Начать.html** в браузере. Задания, формы проверки и таймер работают локально. Вкладки А–Е можно проходить по очереди.
2. Для практики в 1С создай две отдельные базы на основе локальной стартовой УНФ, назови «ОфисПро Производство» и «ОфисПро Трейд». Исходный DT и его SHA-256 лежат в соседней папке предыдущего комплекта «Тренировка/Старт». Сохрани копию обеих учебных баз до начала работы.
3. В локальном комплекте **Исходники/Данные.xlsx** — каталог производителя, **Исходники/feature.feature** — исходный сценарий Vanessa. Распакуй **Картинки.zip** в отдельную папку: внутри 38 учебных JPG, имена совпадают с артикулами. Картинки созданы специально для этого тура. При первом запуске ограничься этими файлами.
4. Перед модулем В введи в Трейде восемь начальных карточек и остатки из таблицы на странице задания. Сохрани копию Трейда после синхронизации и до заказа модуля Г. Из неё удобно проходить Д без незакрытых заказов и ожидаемых поставок.
5. После каждого модуля выполни проверку на его вкладке. Затем пройди строки листа и поставь флажки за то, что можешь показать в 1С. Запиши ссылку на документ или имя отчёта. Кнопка **Скачать протокол** сохраняет состояние всех 68 строк, результат последней проверки каждого модуля и заметки. Храни протокол перед сменой браузера или переносом папки. Локальная HTML-страница и страница сервиса сохраняют отдельные попытки.
6. После самостоятельного прохода открой **Ключ.md**. В локальной папке **Исходники/Разбор после попытки** лежат пять исходных описаний сессий и два CFE. Сравнивай своё решение с расширениями на отдельных копиях баз. Для шестого модуля подготовлена авторская репетиция защиты.

| Модуль | Что выполнить | Время | Критерии | Баллы |
|---|---|---:|---:|---:|
| А | Импорт, дерево, остатки и цены на складе производителя | 3 ч | 12 | 21 |
| Б | Публикация OData, клиент, POST и чтение документа | 3 ч | 14 | 20 |
| В | Каталог Трейда и повторная синхронизация без дублей | 3 ч | 15 | 22 |
| Г | Заказ из Трейда, состояния, регламентный опрос и уведомление | 3 ч | 15 | 22 |
| Д | Параметры запасов, рекомендации и заказ поставщику | 1 ч 30 мин | 7 | 10 |
| Е | Трёхминутная защита | 1 ч 30 мин | 5 | 5 |
| **Всего** | | **15 ч** | **68** | **100** |

## Запуск

Открой «Начать.html» для самостоятельной попытки. Чтобы сверить документы в реальной 1С, подготовь Производство и Трейд по методичке и следуй инструкции из папки решения. Для входа используй учётную запись и пароль учебной площадки. Проверочный скрипт запрашивает пароль в терминале.
