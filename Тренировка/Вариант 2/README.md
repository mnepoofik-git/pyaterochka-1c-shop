# ОфисПро. Пробный чемпионат № 2

Для самостоятельного прохода открой [задание 2](Задание.md). Для разбора используй [методичку 2 в Word](Методичка%202.docx) или [версию для браузера](Методика.md).

За 15 часов подготовь две учебные базы УНФ и защити обмен между производителем и торговой компанией. В основе тура реальные 38 артикулов из «Данные.xlsx» практикума. У этого варианта свои заказы, стартовые остатки Трейда и условия закупки. Уровень и веса взяты из тренировочной ведомости на 68 строк. Итог в тренажёре — твоя самооценка.

1. Распакуй комплект целиком в обычную папку. Открой **Начать.html** в браузере. Задания, формы проверки и таймер работают локально. Вкладки А–Е можно проходить по очереди.
2. Для практики в 1С создай две отдельные базы на основе локальной стартовой УНФ, назови «ОфисПро Производство» и «ОфисПро Трейд». Исходный DT и его SHA-256 лежат в соседней папке предыдущего комплекта «Тренировка/Старт». Сохрани копию обеих учебных баз до начала работы.
3. В локальном комплекте **Исходники/Данные.xlsx** — каталог производителя, **Исходники/feature.feature** — исходный сценарий Vanessa. Распакуй **Картинки.zip** в отдельную папку: внутри 38 учебных JPG, имена совпадают с артикулами. Картинки созданы специально для этого тура. При первом запуске ограничься этими файлами.
4. Перед модулем В введи в Трейде восемь начальных карточек и остатки из таблицы на странице задания. Сохрани копию Трейда после синхронизации и до заказа модуля Г. Из неё удобно проходить Д без незакрытых заказов и ожидаемых поставок.
5. После каждого модуля выполни проверку на его вкладке. Затем пройди строки листа и поставь флажки за то, что можешь показать в 1С. Запиши ссылку на документ или имя отчёта. Кнопка **Скачать протокол** сохраняет состояние всех 68 строк, результат последней проверки каждого модуля и заметки. Храни протокол перед сменой браузера или переносом папки. Локальная HTML-страница и страница сервиса сохраняют отдельные попытки.
6. После самостоятельного прохода открой **Ключ.md**. В локальной папке **Исходники/Разбор после попытки** лежат пять исходных описаний сессий и два CFE. Сравнивай своё решение с расширениями на отдельных копиях баз. Для шестого модуля подготовлена авторская репетиция защиты.

| Модуль | Что выполнить | Время | Критерии | Баллы |
|---|---|---:|---:|---:|
| А | Импорт, дерево, остатки и цены на складе производителя | 3 ч | 12 | 21 |

## Учебный сервис для обращения из 1С

Требуется Python 3.9 или новее. В терминале открой папку «Вариант 2» и запусти команду для своей системы.

macOS или Linux

```sh
python3 Сервис/server.py
```

Windows PowerShell

```powershell
py -3 .\Сервис\server.py
```

На запрос пароля введи учебное значение `123`. Ввод скрыт. Сервис работает на компьютере, где запущен Python. Открой в браузере **http://127.0.0.1:8082/**. Это те же задания плюс чтение заказов из эмулятора на вкладках Б и Г. Раздел с паролем находится под кнопкой сверки. Если хочешь проверить локальную УНФ, возьми JSON из её публикации и вставь в форму вручную.

| Параметр клиента 1С | Значение для учебного сервиса |
|---|---|
| Сервер и порт | 127.0.0.1, порт 8082 |
| Корень | /unf_production/odata/standard.odata/ |
| Имя | odata_user |
| Проверка соединения | GET корня с авторизацией возвращает 200, без неё — 401 |
| Метаданные | GET $metadata возвращает XML, запросы данных возвращают JSON |
| Данные | Catalog_Номенклатура, AccumulationRegister_Запасы/Balance(), InformationRegister_ЦеныНоменклатуры/SliceLast(), Document_ЗаказПокупателя |
| Ошибки для репетиции | Неизвестный ресурс отдаёт 404, Training_Error500 отдаёт 500 |
| Пагинация | Читай value и переходи по odata.nextLink, пока ссылка есть. До семи записей на страницу |
| Смена статуса | На Г введи UID и пароль, нажми «Перевести учебный заказ в работу», затем опроси его из своей обработки |

На 1С-клиенте HTTP-вызов выполняется там, где исполняется твой код. Для обращения к 127.0.0.1 серверное выполнение 1С и эмулятор должны находиться на одном компьютере. Эмулятор нужен для отладки HTTP-клиента. Публикацию, права, реальные документы, журнал и регламентный обмен демонстрируй в собственных базах УНФ. В своей базе проверь имена наборов и полей по её $metadata. Для дополнительной попытки с пустым журналом заказов запусти сервер с аргументом `--db attempt2.sqlite3`. Остановка сервера — Ctrl+C.

### Пример запросов для модуля Б

Пути ниже указаны относительно корня. Параметры формируй с URL-кодированием. Для отладки в 1С посылай Basic-аутентификацию и заголовок Accept со значением application/json.

```text
GET Catalog_Номенклатура?$filter=IsFolder eq false&$select=Ref_Key,Description,Артикул&$orderby=Description asc&$format=json
GET Catalog_Номенклатура?$filter=Артикул eq '1002'&$format=json
GET Catalog_Контрагенты?$filter=Description eq 'ОфисПро Трейд'&$format=json
POST Document_ЗаказПокупателя?$format=json
GET Document_ЗаказПокупателя(guid'<UID заказа>')?$expand=Контрагент&$format=json
```

В теле POST замени три подписи фактическими UID из своих GET. Заголовок Content-Type — application/json. Для проверки создай заказ кнопкой своей обработки 1С. Сверяй именно документ по полученному Ref_Key.

```json
{
  "Date": "2026-12-01T12:00:00",
  "Контрагент_Key": "<UID покупателя>",
  "Запасы": [
    {"Номенклатура": "<UID 1002>", "Номенклатура_Type": "StandardODATA.Catalog_Номенклатура", "Количество": 3, "Цена": 65},
    {"Номенклатура": "<UID 5001>", "Номенклатура_Type": "StandardODATA.Catalog_Номенклатура", "Количество": 2, "Цена": 85}
  ]
}
```

## Если ты скачал вариант из ветки GitHub

В публичной папке лежат авторские задания, проверка, картинки и код учебного сервиса. На компьютере с исходным комплектом практикума положи «Данные.xlsx» и «feature.feature» в папку «Исходники» рядом с «Начать.html». Если русские имена в ZIP отображаются неверно, для запуска эмулятора можешь прямо передать путь к архиву. На macOS можно перетащить сам архив из Finder в терминал после пробела в конце команды.

```sh
python3 Сервис/prepare.py "/путь/к/Материалы.zip"
python3 Сервис/server.py
```

Скрипт принимает также путь к исходной книге или папке practicumunf2. На Windows используй команду `py -3` вместо `python3`. Первичные материалы доступны в твоём локальном комплекте и в приложении к практикуму. [Практикум 1С:УНФ на ИТС](https://its.1c.ru/db/pubunfpracticum2)
