# Как подключить примеры практикума к стартовой УНФ

Проверено на macOS с платформой **1С:Предприятие 8.5.1.1522**. Общий стартовый DT содержит **«Управление небольшой фирмой», учебную версию 3.0.9.150**. У этой конфигурации режим совместимости **8.3.24**. У обоих присланных CFE установлен режим **8.3.27**. Номер установленной платформы и режим в свойствах конфигурации задаются отдельно.

## Какие файлы взять

Для самостоятельной попытки возьми исходный Excel и создай свои расширения. Когда захочешь свериться с реализацией практикума, распакуй локальный ZIP варианта 2. Внутри «Исходники/Разбор после попытки/Для стартовой УНФ 3.0.9.150» находятся два CFE с согласованным режимом.

| Копия базы | Локальный файл | Имя расширения в Конфигураторе |
|---|---|---|
| ОфисПро Производство | ОфисПро Производство для УНФ 3.0.9.150.cfe | ЗагрузкаНоменклатуры |
| ОфисПро Трейд | ОфисПро Трейд для УНФ 3.0.9.150.cfe | ОбменНоменклатурой |

1. Восстанови общий учебный DT в две отдельные базы. Обе открывай через платформу 8.5.1.1522.
2. В Конфигураторе производителя открой «Конфигурация → Расширения конфигурации». Загрузи CFE производителя, обнови конфигурацию базы данных и проверь активность расширения.
3. Повтори в базе Трейда с её файлом. Открой список расширений, чтобы сверить имя и активность.
4. Для собственной обработки загрузки картинок возьми JPG из Картинки.zip. Исходный пример производителя собирает путь из диска D: и артикула. При разборе на Mac замени этот участок на путь к распакованным JPG, доступный той стороне 1С, на которой читается файл.
5. Публикацию, чтение остатков и цен, отправку и переход состояния проверяй по модулям Б–Г. Баллы за эти действия ставь после показа в своих базах.

В копиях CFE для локального комплекта изменено свойство ConfigurationExtensionCompatibilityMode с Version8_3_27 на Version8_3_24. Исходные CFE лежат уровнем выше. Программные модули образцов сохранены. На проверочном стенде 1С загрузила расширения, проверила метаданные и обновила структуру обеих баз. В списке расширений обоим присвоен признак active=yes. Сохранённые CFE повторно загружены из файлов и применены платформой с кодом завершения 0. Это проверка установки и применения. Работа форм, расписание и полный пользовательский сценарий требуют отдельного прогона.

Если у тебя только файлы из GitHub и свой комплект практикума, открой копию расширения в Конфигураторе 8.5.1. В корневых свойствах расширения выбери для режима совместимости значение «Версия 8.3.24». Сохрани под отдельным именем, обнови учебную базу и затем проверь активность в списке. В ветке опубликована эта инструкция; производные бинарные файлы практикума входят в локальный ZIP.
