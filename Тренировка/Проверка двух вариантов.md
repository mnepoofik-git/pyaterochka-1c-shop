# Проверка двух вариантов ОфисПро

Для второго варианта выпущено отдельное решение 2.0. Самооценка комплекта — **88,5/100** на наборе из 38 товаров. [Актуальные проверки в УНФ](Вариант%202/Разбор%20после%20попытки/Решение/Результат.md). Числа 19,5 и 42 ниже относятся к присланным образцам до доработки.

| Вариант | Данные | Оценка комплекта |
|---|---|---:|
| 1 | Домашний каталог, 500 товаров | 78,5/100 |
| 2 | Книга практикума, 38 товаров | 88,5/100 |

Для самостоятельной попытки сначала открой задание своего варианта. После попытки сравни результаты с соответствующей методичкой. Для варианта 2 на GitHub доступен сокращённый протокол. Построчная сверка хранится в локальном комплекте. Историческая оценка исходных образцов варианта 2 вынесена в его ведомость.
