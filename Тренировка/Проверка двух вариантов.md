# Проверка двух вариантов ОфисПро

**Вариант 1.** Заочная оценка реализованного решения 0.2.6 на домашнем наборе составляет **78,5 из 100**. Пересчитаны все 68 записей сохранённой оценки и сверены SHA-256 обеих ранее проверенных выгрузок DT. В этом проходе также выполнены четыре теста тренажёра. Подробности проверки баз зафиксированы в исходном протоколе 0.2.6.

**Вариант 2.** Проверен учебный комплект на 38 товаров. При оценке именно моей сдачи по 68 строкам документально подтверждён **1 балл за описание API**. Балл за полное выступление участника на этом варианте пока не установлен. Эмулятор, образцы фирмы 1С, методичка и ключ имеют разные назначения. Ниже указано, какое дополнительное доказательство нужно для каждой строки.

Платформа 8.3.27.1936 успешно развернула стартовый DT. На отдельных копиях базы загрузка каждого CFE из практикума вернула код 255 с требованием версии 8.5.1 или новее. Проверка установки CFE сама по себе не приносит баллов за разработку.
