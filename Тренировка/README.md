# Тренировка ОфисПро по 68 критериям

Откройте [полную методику в браузере](Методика.md) или [скачайте версию Word](Методика%20подготовки%20по%2068%20критериям.docx). Для каждой оценочной строки указаны реализация, проверка и наблюдаемый результат на максимальный балл. Записывайте собственные баллы и доказательства в [чистый лист самопроверки](Самопроверка/Лист%20самопроверки.xlsx).

## Первый запуск

1. Из папки [Старт](Старт/) возьмите задание 04, ведомость 05 и инфраструктурный лист 02. Распакуйте учебный архив каталога. Внутри Excel с 500 строками и папка images с 500 PNG. Остаток в домашнем комплекте — 486 150 шт. В ведомости для комплекта площадки указан итог 130 983 шт.
2. Исходная база **unf_3_0.dt** хранится в локальном комплекте, в папке «Старт». Размер 1 087 118 775 байт. Для копии с GitHub положите свой исходный DT рядом с [контрольной суммой](Старт/unf_3_0.dt.sha256). На Mac из этой папки выполните `shasum -a 256 -c unf_3_0.dt.sha256`. В Windows используйте `Get-FileHash .\unf_3_0.dt -Algorithm SHA256` и сравните значение.
3. Создайте две **пустые** файловые базы. В Конфигураторе каждой выполните «Администрирование → Загрузить информационную базу» и укажите исходный DT. Операция заменяет содержимое выбранной базы. Работайте с раздельными копиями «ОфисПро Производство» и «ОфисПро Трейд».
4. Начните с модуля А в методичке. Распакуйте [OfficePro-Practice.zip](Самопроверка/OfficePro-Practice.zip), откройте терминал в папке с trainer.py и выполните `python3 trainer.py` на Mac или `py -3 trainer.py` в Windows. Задайте учебный пароль. Откройте `http://127.0.0.1:8080/practice`.
5. После каждого модуля внесите балл и основание в лист «Попытка». Для новой репетиции сохраните отдельную копию XLSX. Сводка покажет набранные баллы и сколько строк подтверждено.

## Материалы для самопроверки

| Файл | Как использовать |
| --- | --- |
| Лист самопроверки.xlsx | Вписывайте балл и основание. Сводка охватывает 68 строк и 100 баллов. |
| OfficePro-Practice.zip | Браузерные упражнения А–Е, репетиционный HTTP-сервис и две Python-проверки. Внутри PRACTICE.md приведены команды и формат выгрузок. |
| Исходники расширения.zip | Сравните код BSL с собственным решением. Особенности образца 0.2.6 и места доработки для максимума по строкам 20, 48, 68, 71, 72 и 86 разобраны в методике. |
| Рекомендации к закупке.xlsx | Сверьте результат своей выгрузки для восьми контрольных позиций с расчётом на пять строк и 1 150 шт. |
| Пополнение.feature | Пример сценария Vanessa для обработки пр_Пополнение. Для показа штатного расчёта УНФ подставьте команды и элементы реальной формы и выполните сценарий на своей базе. |
| Старт/Проверить каталог.py | Проверяет исходный домашний архив, состав Excel, штрихкоды, цены и соответствие артикулов файлам PNG. Запускается через Python 3 из любой папки. |

Прежние разработки сохранены в унаследованной папке championship репозитория. Для оценки используйте ведомость 05 из этого комплекта. Интерактивные ответы и Excel дают учебную самооценку. Права пользователя и интерфейс проверяют в УНФ, плановый запуск — по истории выполнения, охрану труда и защиту — наблюдением.
