# Вариант 1. Сверка после попытки

| Модуль | Контрольный результат |
|---|---|
| А | 500 элементов, 3 корня, 6 подгрупп, 6 подподгрупп. Два вида цен дают 1 000 строк, общий остаток домашнего производителя 486 150 шт. У каждого артикула один PNG и уникальный код. |
| Б | На 15.01.2027 УЧ-0001 × 2 по 83 ₽ и УЧ-0002 × 3 по 90 ₽ дают 436 ₽. POST из своей обработки вернул UID, отдельный GET открыл тот же заказ. |
| В | В чистой базе после предварительного ввода восьми карточек первая синхронизация создаёт ещё 492 товара. Вторая добавляет 0. В регистре 500 устойчивых товарных связей UID. |
| Г | Новый внешний UID открывает созданный заказ производителя. При изменении состояния менеджер получает одно уведомление. Повторный опрос без перехода оставляет прежнее количество. |
| Д | Для артикулов из таблицы задания в её порядке рекомендации составляют 380, 315, 140, 0, 0, 115, 0, 200. В заказе 5 строк на 1 150 шт. |
| Е | Полный показ укладывается в три минуты. Слушатель может назвать действие менеджера, измеренный результат и способ проверить его в базе. |

По каждой из 68 строк подробные действия и доказательства находятся в [методичке](Методика.md). Заполняй свой протокол отдельно от заполненной оценки образца в «Разбор после попытки».
