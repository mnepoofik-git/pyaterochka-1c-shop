# Вариант 1. Самостоятельный чемпионат ОфисПро

Этот вариант подготовлен по конкурсному заданию АБП на домашнем каталоге из 500 товаров. Начни с [задания](Задание.md). Разбирай сложные места по [методичке 1 в Word](Методичка%201.docx) или [читай её в браузере](Методика.md). В конце открой [ключ](Ключ.md).

1. Для работы в 1С сделай две независимые учебные базы «Производство 1» и «Трейд 1» из локального исходного unf_3_0.dt. Исходный файл на Mac находится в общей папке «Тренировка/Старт». Контрольная сумма есть в папке «Старт» этого комплекта. Официальное задание, ведомость, инфраструктурный лист и учебные данные находятся там же.
2. Распакуй архив каталога из «Старт». Для тренажёра распакуй **Самопроверка/OfficePro-Practice.zip**. В терминале перейди в распакованную папку **OfficePro-Practice**, где лежит trainer.py, и выполни команду для своей системы.

   macOS: `python3 trainer.py --port 8081`  
   Windows: `py -3 trainer.py --port 8081`

3. При запросе введи учебный пароль `123`. Открой **http://127.0.0.1:8081/practice**. Учебный клиент OData доступен на **http://127.0.0.1:8081/**. Корень для HTTP из 1С — `/unf_production/odata/standard.odata/`. В полной публикации УНФ используй адрес своей базы.
4. Проверь строки модулей и сохрани свой отчёт из тренажёра. Для дробных оценок веди отдельную копию **Самопроверка/Лист самопроверки.xlsx**. В «Разбор после попытки» лежат расширение версии 0.2.6, протокол и прежняя заочная оценка образца.
