# Конфигурация 1С для магазина у дома

Неофициальный демонстрационный проект для розничного магазина, подготовленный по запросу пользователя. Он не является продуктом или официальной конфигурацией сети «Пятёрочка».

## Что внутри

- `build/МагазинПятерочка.cf` — файл конфигурации для загрузки в Конфигуратор платформы 1С:Предприятие 8.3.27.
- `source/edt-project/` — исходный проект формата EDT.
- `source/xml-export/` — XML-выгрузка метаданных и начальных демонстрационных записей справочников.
- `demo/pyaterochka-demo.dt` — восстановимая демонстрационная информационная база; данные полностью вымышлены.
- `demo/README.md` — перечень демонстрационных данных и инструкция по восстановлению.
- `docs/Проектный-пакет.md` — описание структуры и возможностей конфигурации.
- `WORKLOG.md` — журнал выполненных действий и принятых технических решений.

## Состав конфигурации

Справочники: номенклатура, магазины, склады, поставщики и кассы ККМ.

Документы: поступление товаров, розничная продажа и инвентаризация товаров.

Регистры: товары на складах, продажи и цены номенклатуры.

## Демонстрационные данные

В `.dt` есть магазин, склад, поставщик, касса и 10 товаров. Документы, цены и движения по регистрам не загружены. База предназначена для тестового ввода; реальные адреса и контакты в ней отсутствуют.

## Загрузка файла CF

1. Откройте пустую конфигурацию в Конфигураторе.
2. Выберите **Конфигурация → Загрузить конфигурацию из файла…**.
3. Укажите `build/МагазинПятерочка.cf` и подтвердите замену конфигурации.
4. Обновите конфигурацию базы данных клавишей **F7**.

Сборка подготовлена платформой 8.3.27.1936 с совместимостью 8.3.27. Перед использованием в реальной работе проверьте конфигурацию на целевой базе и настройте учётную политику, права, оборудование и обязательную отчётность.

## Границы демонстрационной версии

В проект не входят интеграции с фискальным регистратором и торговым оборудованием, обмен с центральной системой торговой сети, бухгалтерский и налоговый учёт, маркировка, автозаказ, полноценная ролевая модель и производственные отчёты. Эти требования требуют отдельного обследования и разработки.
